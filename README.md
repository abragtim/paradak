# Парадак

Простая праграма па-беларуску, каб навесці парадак на Mac: ачысціць часовыя файлы, выдаліць праграму
і паглядзець, што займае месца. Бясплатна, macOS 14 і навейшыя, Apple Silicon і Intel.

**[Спампаваць](https://abragtim.github.io/paradak/)** · [усе выпускі](https://github.com/abragtim/paradak/releases)

A simple Belarusian-language Mac cleaner. Free of charge, closed source ([licence](LICENSE)).
This repository holds only the download page and the materials required for the bundled
[Mole](mole/README.md) (GPL-3.0).
